A canonical, accessible block theme starter generated from the
wordpress-block-theme Claude skill. Rename the theme and replace the design
tokens in theme.json before shipping.

Note: screenshot.png ships as a placeholder. Optionally run `bin/screenshot.sh`
(requires Docker/wp-env + Chrome) to generate a best-effort 1200x900 homepage
capture — but still hand-pick and review a final 1200x900 capture before
shipping.
